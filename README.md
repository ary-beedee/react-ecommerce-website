# React E-Commerce Website

A simple e-commerce application built using React and MongoDB

## Features

- Product Listing
- Product Details Page
- Shopping Cart
- Bill Summary

## Tech Stack

- HTML
- CSS
- JavaScript
- React
- React Router DOM
- Context API
- MongoDB
