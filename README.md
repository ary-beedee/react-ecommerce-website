# React E-Commerce Website

A simple e-commerce application built using React and Vite.

## Features

- Product Listing
- Product Details Page
- Shopping Cart
- Bill Summary

## Tech Stack

- React
- Vite
- React Router DOM
- Context API
- CSS
- DummyJSON API

## API

https://dummyjson.com/products?limit=194

## Installation

```bash
npm install
npm run dev
```
